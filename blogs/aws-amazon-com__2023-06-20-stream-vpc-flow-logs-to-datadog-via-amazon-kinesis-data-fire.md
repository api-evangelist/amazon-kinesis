<p><em><strong>February 9, 2024:</strong> Amazon Kinesis Data Firehose has been renamed to Amazon Data Firehose. Read the <a href="https://aws.amazon.com/about-aws/whats-new/2024/02/amazon-data-firehose-formerly-kinesis-data-firehose/" rel="noopener" target="_blank">AWS What’s New post</a> to learn more.</em></p> 
<p>It’s common to store the logs generated by customer’s applications and services in various tools. These logs are important for compliance, audits, troubleshooting, security incident responses, meeting security policies, and many other purposes. You can perform log analysis on these logs to understand users’ application behavior and patterns to make informed decisions.</p> 
<p>When running workloads on Amazon Web Services (AWS), you need to analyze <a href="https://docs.aws.amazon.com/vpc/latest/userguide/what-is-amazon-vpc.html" rel="noopener" target="_blank">Amazon Virtual Private Cloud</a> (Amazon VPC) <a href="https://docs.aws.amazon.com/vpc/latest/userguide/flow-logs.html" rel="noopener" target="_blank">Flow Logs</a> to track the IP traffic going to and from the network interfaces for the workloads in their VPC. Analyzing VPC flow logs helps you understand how your applications are communicating over the VPC network and acts as a main source of information to the network in your VPC.</p> 
<p>You can easily deliver data to supported <a href="https://docs.aws.amazon.com/firehose/latest/dev/create-destination.html" rel="noopener" target="_blank">destinations</a> using the <a href="https://aws.amazon.com/kinesis/data-firehose/" rel="noopener" target="_blank">Amazon Kinesis Data Firehose</a> integration with VPC flow logs. Kinesis Data Firehose is a fully managed service for delivering near-real-time streaming data to various destinations for storage and performing near-real-time analytics. With its extensible data transformation capabilities, you can also streamline log processing and log delivery pipelines into a single Kinesis Data Firehose delivery stream. You can perform analytics on VPC flow logs delivered from your VPC using the Kinesis Data Firehose integration with <a href="https://www.datadoghq.com/" rel="noopener" target="_blank">Datadog</a> as a destination.</p> 
<p>Datadog is a monitoring and security platform and <a href="http://aws.amazon.com/partners" rel="noopener" target="_blank">AWS Partner Network</a> (APN) Advanced Technology Partner with <a href="https://aws.amazon.com/partners/find/partnerdetails/?n=Datadog%20Inc&amp;id=001E000000Rp57sIAB" rel="noopener" target="_blank">AWS Competencies in AWS Cloud Operations, DevOps, Migration, Security, Networking, Containers, and Microsoft Workloads</a>, along with many others.</p> 
<p>Datadog enables you to easily explore and analyze logs to gain deeper insights into the state of your applications and AWS infrastructure. You can <a href="https://www.datadoghq.com/blog/logging-without-limits/" rel="noopener" target="_blank">analyze</a> all your AWS service logs while storing only the ones you need, <a href="https://www.datadoghq.com/blog/logging-without-limits-new-features/#generate-metrics-from-logs" rel="noopener" target="_blank">generate metrics</a> from aggregated logs to uncover, and send alerts about trends in your AWS services.</p> 
<p>In this post, you learn how to integrate VPC flow logs with Kinesis Data Firehose and deliver it to Datadog.</p> 
<h2>Solution overview</h2> 
<p>This solution uses native integration of VPC flow logs streaming to Kinesis Data Firehose. We use a Kinesis Data Firehose delivery stream to buffer the streamed VPC flow logs to a Datadog destination endpoint in your Datadog account. You can use these logs with Datadog Log Management and Datadog Cloud SIEM to analyze the health, performance, and security of your cloud resources.</p> 
<p>The following diagram illustrates the solution architecture.</p> 
<p><img alt="" class="alignnone wp-image-49198 size-full" height="287" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/13/BDB-2630-image001-new.png" style="margin: 10px 0px 10px 0px;" width="479" /></p> 
<p>We walk you through the following high-level steps:</p> 
<ol> 
 <li>Link your AWS account with your <a href="https://docs.datadoghq.com/integrations/amazon_web_services/#setup" rel="noopener" target="_blank">Datadog account</a>.</li> 
 <li>Create the Kinesis Data Firehose stream where VPC service streams the flow logs.</li> 
 <li>Create the VPC flow log subscription to Kinesis Data Firehose.</li> 
 <li>Visualize VPC flow logs in the Datadog dashboard.</li> 
</ol> 
<p>The account ID 123456781234 used in this post is a dummy account. It is used only for demonstration purposes.</p> 
<h2>Prerequisites</h2> 
<p>You should have the following prerequisites:</p> 
<ul> 
 <li>An <a href="http://aws.amazon.com/s3" rel="noopener" target="_blank">Amazon Simple Storage Service</a> (Amazon S3) bucket to store the Firehose delivery stream backups and failed logs.</li> 
 <li>A Datadog account is needed. If you don’t already have an account, visit the Datadog website to sign up for a <a href="https://datadoghq.com" rel="noopener" target="_blank">free 14-day trial</a>.</li> 
 <li>A <a href="https://app.datadoghq.com/organization-settings/api-keys" rel="noopener" target="_blank">Datadog API key</a> needed for submitting logs to Datadog.</li> 
 <li><a href="http://aws.amazon.com/iam" rel="noopener" target="_blank">AWS Identity and Access Management</a> (IAM) permission to create and modify IAM roles and policies.</li> 
</ul> 
<h2>Link your AWS account with your Datadog account for AWS integration</h2> 
<p>Follow the <a href="https://docs.datadoghq.com/integrations/amazon_web_services/#setup" rel="noopener" target="_blank">instructions</a> provided on the Datadog website for AWS Integration. To configure <a href="https://docs.datadoghq.com/logs/log_configuration/archives/?tab=awss3" rel="noopener" target="_blank">log archiving</a> and enrich the log data sent from your AWS account with useful context, link the accounts. When you complete the linking setup, proceed to the following step.</p> 
<h2>Create a Kinesis Data Firehose stream</h2> 
<p>Now that your Datadog integration with AWS is complete, you can create a Kinesis Data Firehose delivery stream where VPC Flow Logs are streamed by following these steps:</p> 
<ol> 
 <li>On the Amazon Kinesis console, choose <strong>Kinesis Data Firehose</strong> in the navigation pane.</li> 
 <li>Choose <strong>Create delivery stream</strong>.</li> 
 <li>Choose <strong>Direct PUT</strong> as the source.</li> 
 <li>Set <strong>Destination </strong>as<strong> Datadog</strong>.<br /> <a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image003.png"><img alt="Create delivery stream" class="alignnone size-full wp-image-48871" height="316" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image003.png" style="margin: 10px 0px 10px 0px;" width="543" /></a></li> 
</ol> 
<ol start="5"> 
 <li>For <strong>Delivery stream name</strong>, enter <code>PUT-DATADOG-DEMO</code>.</li> 
 <li>Keep <strong>Data transformation</strong> set to <strong>Disabled</strong> under <strong>Transform records</strong>.</li> 
 <li>In <strong>Destination settings</strong>, for <strong>HTTP endpoint URL</strong>, choose the desired log’s HTTP endpoint based on your Region and Datadog account configuration.<br /> <a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image005.png"><img alt="Kinesis delivery stream configuration" class="alignnone size-full wp-image-48870" height="862" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image005.png" style="margin: 10px 0px 10px 0px;" width="540" /></a></li> 
 <li>For <strong>API key</strong>, enter your <a href="https://app.datadoghq.com/organization-settings/api-keys" rel="noopener" target="_blank">Datadog API key</a>.</li> 
</ol> 
<p>This allows your delivery stream to publish VPC Flow logs to the Datadog endpoint. API keys are unique to your organization. An <a href="https://app.datadoghq.com/organization-settings/api-keys" rel="noopener" target="_blank">API key</a> is required by the Datadog Agent to submit metrics and events to Datadog.</p> 
<ol start="9"> 
 <li>Set <strong>Content encoding</strong> to <strong>GZIP</strong> to reduce the size of data transferred.</li> 
 <li>Set the <strong>Retry duration</strong> to <strong>60</strong>.You can change the <strong>Retry duration</strong> value if you need to. This depends on the request handling capacity of the Datadog endpoint.<br /> <a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image007.png"><img alt="Kinesis destination settings" class="alignnone size-full wp-image-48869" height="586" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image007.png" style="margin: 10px 0px 10px 0px;" width="540" /></a><br /> Under <strong>Buffer hints</strong>, <strong>Buffer size</strong> and <strong>Buffer interval</strong> are set with default values for Datadog integration.<br /> <a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image009.png"><img alt="Kinesis buffer settings" class="alignnone size-full wp-image-48868" height="280" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image009.png" style="margin: 10px 0px 10px 0px;" width="540" /></a></li> 
</ol> 
<ol start="11"> 
 <li>Under <strong>Backup settings</strong>, as mentioned in the prerequisites, choose the S3 bucket that you created to store failed logs and backup with specific prefix.</li> 
 <li>Under <strong>S3 buffer hints</strong> section, set <strong>Buffer size</strong> to 5 and <strong>Buffer interval</strong> to 300.</li> 
</ol> 
<p>You can change the S3 buffer size and interval based on your requirements.</p> 
<ol start="13"> 
 <li>Under <strong>S3 compression and encryption</strong>, select <strong>GZIP</strong> for <strong>Compression for data records</strong> or another compression method of your choice.</li> 
</ol> 
<p>Compressing data reduces the required storage space.</p> 
<ol start="14"> 
 <li>Select <strong>Disabled </strong>for<strong> Encryption of the data records</strong>. You can enable encryption of the data records to secure access to your logs.<br /> <a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image011.png"><img alt="Kinesis stream backup settings" class="alignnone size-full wp-image-48867" height="846" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image011.png" style="margin: 10px 0px 10px 0px;" width="539" /></a></li> 
</ol> 
<ol start="15"> 
 <li>Optionally, in <strong>Advanced settings</strong>, select <strong>Enable server-side encryption for source records in delivery stream</strong>.<br /> You can use <a href="https://docs.aws.amazon.com/kms/latest/developerguide/concepts.html#aws-managed-cmk" rel="noopener" target="_blank">AWS managed keys</a> or a <a href="https://docs.aws.amazon.com/kms/latest/developerguide/concepts.html#customer-cmk" rel="noopener" target="_blank">CMK</a> managed by you for the encryption type.</li> 
</ol> 
<ol start="16"> 
 <li>Enable <strong>CloudWatch error logging</strong>.</li> 
 <li>Choose <strong>Create or update IAM role</strong>, which is created by Kinesis Data Firehose as part of this stream.<br /> <a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image013.png"><img alt="Kinesis stream Advanced settings" class="alignnone size-full wp-image-48866" height="526" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image013.png" style="margin: 10px 0px 10px 0px;" width="539" /></a></li> 
</ol> 
<ol start="18"> 
 <li>Choose <strong>Next</strong>.</li> 
 <li>Review your settings.</li> 
 <li>Choose <strong>Create delivery stream</strong>.</li> 
</ol> 
<h2>Create a VPC flow logs subscription</h2> 
<p>Create a VPC flow logs subscription for the Kinesis Data Firehose delivery stream you created in the previous step:</p> 
<ol> 
 <li>On the <strong>Amazon VPC </strong>console, choose <strong>Your VPCs</strong>.</li> 
 <li>Select the VPC that you to create the flow log for.</li> 
 <li>On the <strong>Actions</strong> menu, choose <strong>Create flow log</strong>.<br /> <a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image015.png"><img alt="AWS VPCs" class="alignnone size-full wp-image-48865" height="239" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image015.png" style="margin: 10px 0px 10px 0px;" width="779" /></a></li> 
</ol> 
<ol start="4"> 
 <li>Select <strong>All</strong> to send all flow log records to the Firehose destination.</li> 
</ol> 
<p>If you want to filter the flow logs, you could alternatively select <strong>Accept </strong>or <strong>Reject</strong>.</p> 
<ol start="5"> 
 <li>For <strong>Maximum aggregation interval</strong>, select <strong>10 minutes</strong> or the minimum setting of <strong>1 minute</strong> if you need the flow log data to be available for near-real-time analysis in Datadog.</li> 
 <li>For <strong>Destination</strong>, select <strong>Send to Kinesis Data Firehose in the same account </strong>if the delivery stream is set up on the same account where you create the VPC flow logs.</li> 
</ol> 
<p>If you want to send the data to a different account, refer to <a href="https://docs.aws.amazon.com/vpc/latest/userguide/flow-logs-firehose.html" rel="noopener" target="_blank">Publish flow logs to Kinesis Data Firehose</a>.</p> 
<ol start="7"> 
 <li>Choose an option for <strong>Log record format:</strong></li> 
 <li>If you leave <strong>Log record format</strong> as the <strong>AWS default format</strong>, the flow logs are sent as <a href="https://docs.aws.amazon.com/vpc/latest/userguide/flow-logs.html#flow-logs-default" rel="noopener" target="_blank">version 2 format</a>.</li> 
 <li>Alternatively, you can specify the custom fields for flow logs to capture and send it to Datadog.</li> 
</ol> 
<p>For more information on log format and available fields, refer to <a href="https://docs.aws.amazon.com/vpc/latest/userguide/flow-logs.html#flow-log-records" rel="noopener" target="_blank">Flow log records</a>.</p> 
<ol start="10"> 
 <li>Choose <strong><strong>Create flow log.</strong></strong><br /> <a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image017.png"><img alt="Create VPC Flow log" class="alignnone size-full wp-image-48864" height="1001" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image017.png" style="margin: 10px 0px 10px 0px;" width="557" /></a></li> 
</ol> 
<p>Now let’s explore the VPC flow logs in Datadog.</p> 
<h2>Visualize VPC flow logs in the Datadog dashboard</h2> 
<p>In the <strong>Logs Search option</strong> in the navigation pane, filter to <code>source:vpc</code>. The VPC flow logs from your VPC are in the Datadog Log Explorer and are automatically parsed so you can analyze your logs by source, destination, action, or other attributes.</p> 
<p><a href="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image019.png"><img alt="Datadog Logs Dashboard" class="alignnone size-full wp-image-48863" height="637" src="https://d2908q01vomqb2.cloudfront.net/b6692ea5df920cad691c20319a6fffd7a4a766b8/2023/06/07/BDB-2630-image019.png" style="margin: 10px 0px 10px 0px;" width="1432" /></a></p>

<h2>Conclusion</h2> 
<p>In this post, we walked through a solution of how to integrate VPC flow logs with a Kinesis Data Firehose delivery stream, deliver it to a Datadog destination with no code, and visualize it in a Datadog dashboard. With Datadog, you can easily explore and analyze logs to gain deeper insights into the state of your applications and AWS infrastructure.</p>
